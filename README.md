# Receptes de llum

Del laboratori fotogràfic al filtre digital.

Interactiu web sobre la **remediació** dels processos fotogràfics químics (cianotípia i Van Dyke) en els filtres digitals, i sobre la **transcodificació** que implica: la recepta química es converteix en paràmetres numèrics.

Projecte de l'assignatura _Cultura Digital_ (UOC), PAC 2, 2026 S1.

## Imatges

Les còpies en cianotípia i Van Dyke són pròpies, fetes el maig de 2009 a la Facultat de Belles Arts amb una exposició de 4 minuts al sol directe. La fotografia original també és pròpia.

## Tecnologia

HTML, CSS i JavaScript, sense dependències ni compilació. Publicat amb GitHub Pages.

## Executar en local

Com que fa servir mòduls ES, cal un servidor local:

    python3 -m http.server

i obrir http://localhost:8000.
